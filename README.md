# Python Mini Projects

A collection of small Python mini projects and coding exercises created to practice Python programming concepts.

## Projects

### 1. Number Guessing Game

A simple Python game where the computer generates a random number and the user tries to guess it.

**Concepts Used:**
- Python
- Random module
- User input
- Conditional statements
