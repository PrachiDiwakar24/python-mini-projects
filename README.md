# Python Mini Projects

A collection of small Python mini projects and coding exercises created to practice Python programming concepts.

## Projects

### 1. Number Guessing Game

A simple Python game where the computer generates a random number and the user tries to guess it.

**Concepts Used:**
- Python
- Random module
- User input
- Conditional statements

### 2. Hotel Menu Billing

A simple Python program that displays a hotel menu, allows the user to select food items, and calculates the total bill.

**Concepts Used:**
- Python
- User input
- Conditional statements
- Basic calculations

### 3. Digital Wallet Simulator
A simple Python-based wallet simulator where users can check their balance, add money, and spend money.

**Features:**
- Check wallet balance
- Add money
- Spend money
- Insufficient balance checking
- Exit option

**Concepts Used:**
- `while` loop
- `if-elif-else`
- User input
- Variables
- Arithmetic operations

### 4. Quiz Game
A simple Python quiz game that asks the user multiple questions and checks their answers.

**Features:**
- Multiple quiz questions
- Checks the user's answers
- Shows the correct answer if the user is wrong
- Keeps track of the score
- Displays the final score out of 5

**Concepts Used:**
- `input()`
- `if-else` conditions
- Variables
- String methods
- Score calculation
